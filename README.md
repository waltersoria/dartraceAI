# DAR-Trace AI

Monitoreo hidrogeoquímico y priorización geoespacial de botaderos mineros.

## Organización

- `frontend/`: Angular 20 (pantallas importadas de Google Stitch).
- `backend/`: reservado para futura implementación FastAPI, fuera del alcance de este PR.

## Ejecutar

```bash
cd frontend
npm install
npm start
```

Véase `frontend/README.md` para alcances y limitaciones. Los indicadores del prototipo son datos demostrativos, no mediciones reales.
